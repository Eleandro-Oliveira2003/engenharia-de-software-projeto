[*] --> Disponivel

Disponivel --> Emprestado : retirarLivro

Emprestado --> Atrasado : prazoEntregaExpirou

Emprestado --> Disponivel : devolverLivro [semReserva]
Emprestado --> Reservado : devolverLivro [comReserva]

Atrasado : do / enviarEmailDiario()

Atrasado --> Disponivel : devolverLivro [semReserva]
Atrasado --> Reservado : devolverLivro [comReserva]

Disponivel --> EmInspecao : atingiu15Emprestimos

EmInspecao : do / realizarPequenosReparos()

EmInspecao --> Disponivel : concluirInspecao [semReserva]
EmInspecao --> Reservado : concluirInspecao [comReserva]

Reservado --> Emprestado : retirarLivroReservado
