# Código Java da Parte 3

Compile todos os arquivos no diretório atual com `javac *.java` e rode `java MainTeste`. É necessário ter JDK (o JRE permite executar, mas não compilar).

O método de estratégia recebe endereço, dimensões e peso. Cada estratégia retorna seu valor de teste fixo, conforme a especificação: A 10,00; B 12,00; C 11,00; D 10,50.
